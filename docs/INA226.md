# INA226 I2C Power Monitor (Betaflight 4.5.x)

This firmware integration follows the Texas Instruments INA226 datasheet and calibration guidance for current LSB and calibration register computation, including the shunt voltage full-scale limit and bus voltage LSB size. The driver computes the current LSB as `Imax / 32768` and applies the TI calibration formula `Cal = 0.00512 / (Current_LSB * Rshunt)`. The bus voltage and shunt voltage scalars are derived from the INA226 register LSB values (1.25 mV for bus voltage, 2.5 µV for shunt voltage). Consult the official INA226 datasheet and application notes for the full derivation and register behavior.

## CLI Settings

* `ina226_i2c_address` (default `0x40`): 7-bit I2C address.
* `ina226_shunt_uohm` (default `10000`): shunt resistance in micro-ohms (0.01 Ω typical module value).
* `ina226_max_current_a` (default `0`): optional maximum expected current in amps. If `0`, the driver derives the maximum measurable current from the 81.92 mV shunt range and the configured shunt value.
* `ina226_avg_samples` (default `16`): sample averaging count (1, 4, 16, 64, 128, 256, 512, 1024).
* `ina226_conv_time_us` (default `1100`): per-channel conversion time (140–8244 µs).

The INA226 polling interval is derived from the configured conversion time and averaging count, with a minimum 40 ms interval to keep sampling in the 10–25 Hz range while allowing longer cycles when the configured conversion time requires it.
